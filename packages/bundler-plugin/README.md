# @archwall/bundler-plugin

Shared ArchWall plugin for bundlers exposing webpack's compilation API.

You do not normally install this directly — reach for
[`@archwall/rspack`](../rspack) or [`@archwall/webpack`](../webpack), which are thin
host-shaped surfaces over it. Depend on this package only when writing an adapter for another
webpack-compatible bundler.

Part of [ArchWall](../../README.md).
